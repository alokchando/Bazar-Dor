🛒 BazarDor

BazarDor is a web-based market price tracking application that helps users explore the prices of essential daily products in Bangladesh. Users can browse product categories, compare market prices, and stay informed about the latest available price information through a simple and user-friendly interface.

🚀 Technologies Used

Next.js — React framework for building the web application

React — Component-based user interface

JavaScript — Application logic and functionality

Tailwind CSS — Responsive styling and UI design

DaisyUI — Prebuilt UI components

Better Auth — User authentication and Google sign-in

MongoDB — Database integration for authentication

REST API — Fetching product and market price data

✨ Key Features

Product Categories — Browse essential products, including rice, lentils, oil, vegetables, fish, meat, eggs, and spices.

Product Price Tracking — View available product prices, units, and price changes to understand market trends.

Market Price Comparison — Compare minimum, maximum, and average prices across available market data.

Sorting and Product Details — Sort products by price and explore individual product pages for more information.

User Authentication — Create an account, sign in with email and password or Google, and manage your profile.
